what the verification rounds changed
  • The day sheet no longer claims drifting leads. Drift flags a row in the register; it only reaches the sheet when nothing urgent is left. Otherwise "today" quietly starts meaning "someday". Open count went 5 → 4.
  • The desktop sheet now stretches full height instead of stopping mid-page and leaving the column half-painted.
  • Dropped the full-row yellow wash on desktop. Four washed rows competed with the sheet and stopped reading as a signal; the flag alone carries attention there.
  • Dropped the 8px side tab on Won cards. The mechanical detector flagged it, correctly, as the most recognisable tell of generated UI — and the red column header already carries the meaning.
  • A suspected mobile overflow turned out to be a Chrome headless RTL screenshot artifact, not a bug: measured scrollWidth is exactly 390.
  • All Hebrew now sets in Fredoka. Labels, the day-sheet age tab, column headings, the stamp, the board drop zone and the avatar monogram were in Archivo, which has no Hebrew glyphs — every one of them was silently falling back to a system face. Figures stay Archivo.
  • The row menu was painting under the rows. Not transparency: animation-fill-mode: both left every row holding a stacking context forever. The menu now renders through the CDK overlay, and rows use backwards.
  • The register overflowed between 900 and 1200px, taking the menu trigger off-screen with it. Source and last-touch now drop out until there is width for seven columns.
