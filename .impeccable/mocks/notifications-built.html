Three mechanisms, one rule each

Severity is not a slider. It is one question: can the user safely keep working? Components never pick a mechanism — they report what happened and NotifyService decides. That is what keeps the interrupt rare: exactly one method can raise it, and it takes a failed write.

MechanismFires whenBecause
PopupA write was attempted, failed, and the user believes it succeededThey walk away having lost a real lead. Nothing quieter is honest.
ToastSuccess, info, and every recoverable failureThe work continues; the message is a receipt, not a decision.
BannerOfflineA state with a duration, so it gets a place rather than a moment.

The interrupt set is exactly one case: a change did not persist. Permission-denied, not-found, rate-limited and sign-in failures are toasts. Session expiry is a toast plus a redirect to sign-in — the redirect is the interruption, so a modal would be theatre.

The interrupt

The mark is the product's own object — a lead sheet torn in two, lower fragment displaced — not a stock warning triangle. It stamps into place with the same paper-settling gesture the register uses. Text runs in the order the user thinks: what happened → what it means, naming the record → the recovery. נסה שוב re-runs the exact failed mutation.

The stack and the strip

Toasts and the checklist nudge are the same object in this world, so they share one region and queue instead of colliding. Rule colour encodes kind and every kind carries a mark — colour never signals alone. Above: the offline strip, which pushes content rather than covering it.

Decisions this encodes

  • Retry re-runs the write. The store holds the failed mutation as a closure, so the recovery is one tap rather than "do it all again".
  • Offline blocks writes rather than queueing them. Accepting a write we cannot honour would show the user a lead that does not exist. Nothing is attempted, so nothing is lost — that is a toast, not the popup.
  • A new token, --lf-red-on-ink #ff6a4d. The commit red measures 3.1:1 on an ink ground — barely legal for a mark, illegal for text. Anything red sitting on ink now uses this: 6.6:1.
  • The dashboard's bespoke nudge is gone, replaced by a sticky toast in the shared stack. One object, one place, less markup.
